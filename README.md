# dontgetcaught-privacy

Privacy Policy site for the mobile game **Don't Get Caught!** (들키지 마!).

- Package ID: `com.sneaklab.dontgetcaught`
- Live URL: https://liveasfilm.github.io/dontgetcaught-privacy/
- Developer contact: liveasfilm@gmail.com

The policy is bilingual (Korean + English) and served as a single static
`index.html` via GitHub Pages. No JavaScript, no external assets.

To update the policy, edit [`index.html`](index.html) and update the
"Last updated" date.
